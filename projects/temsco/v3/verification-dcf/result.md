# 제3안 시장·DCF 개편 검증

작성 완료 2026-09-09. 재무·시장 분석 기준일은 2026-09-08로 유지했다.

- 제3안 `/temsco/deck-v3`는 31장이다. 목차의 가치추정 분석은 16~23장으로 분리했다.
- 매출부터 순이익까지 회사 수록 연결 손익을 원 단위 자료에 연결했다. 전체 D&A·영업 현금세금·평가일 이후 CAPEX·운전자본이 미확정이므로 FCFF와 현재 EV는 결측 상태를 유지한다.
- WACC 시장 입력 모듈의 실제 실행, 4개 참고 결과, FCFF 부호·결측 전파, 무성장 TV, 날짜별 할인, 잘못된 날짜·비유한 수치, 자금 부족액·희석 계산을 검산했다. [계산 기록](finance-check.json).
- 범위를 한정한 TypeScript 검사와 Git diff 공백 검사가 exit 0으로 통과했다.
- 브라우저 HTTP 200, 31장, Noto Sans KR 로드, 방향키·Home·End, 직접 해시, 전체 보기, 전체화면, 모바일, 인쇄 모드 확인. 본문·표의 화면 경계 침범과 각주 겹침은 없었다. [브라우저 기록](after-dcf.json).
- 최초 PDF 31장 전체를 독립 렌더링하고 재무·WACC·FCFF·TV 표를 확대 검토했다. 수식과 설명 분리, 매출 금액 단위 명시, 비현금 조정·보통주 용어 개선 후 브라우저와 PDF를 다시 생성했다. 최종 페이지와 접촉표는 `render-final/`에 있다.
- 최종 PDF 페이지 수·크기·텍스트와 SHA-256은 [PDF 기록](pdf-check.json)에 있다. [31장 산출물](../output/TEMSCO-IR-v3-DCF-draft-20260908.pdf).
- 제공 자료 8개와 초기원본·기존 최종본 코드 2개의 SHA-256이 작업 전과 같다. [보존 검증](preservation.json).

확인된 콘솔 알림은 기존 `favicon.ico`의 404 한 건이다. 제3안 런타임 오류는 없었다. 시장 TAM/SAM·회사 점유율, 최종 비교기업 WACC, 현재 EV의 미확정 사항은 검증 실패와 구분하며 [가치추정 분석서](../valuation-analysis.md)에 필요한 입력을 기록했다.
