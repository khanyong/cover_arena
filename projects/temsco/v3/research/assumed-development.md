## NYU 자산화 수치의 정확한 의미

R&DGlobal의 ‘R&D Capitalized’는 **5년 정액상각을 적용한 연구자 추정 연구자산 잔액**. `Variables & FAQ!B5`에서 해당 방법 명시. 실제 기업이 회계상 인식한 당기 개발비 자산화 지출 비중과는 다른 수치.

- 전자부품: 추정 연구자산 **US$164,545.2406m**, LTM R&D **US$56,788.234m**.
- 특수화학: 추정 연구자산 **US$61,965.7306m**, LTM R&D **US$21,130.732m**.
- 연구자산/투하자본 **18.1845% / 6.8573%** 역시 당기 개발비 자산화율과 다른 분모·기간.
- 따라서 ‘5년’은 분석상 수명 참고이며 템스코 실제 내용연수 또는 회계기준상 의무 기간이라는 의미 없음. [NYU R&D 원본 및 FAQ](https://pages.stern.nyu.edu/~adamodar/pc/datasets/R%26DGlobal.xls).

IAS 38은 연구 지출의 비용처리, 요건을 충족하는 개발 지출의 자산인식을 구분. 산업 비율만으로 템스코의 기술적 실현가능성·미래효익·자원 확보·원가 측정 등의 자산인식 요건을 확정할 수 없음. [IFRS Foundation IAS 38 설명](https://www.ifrs.org/issued-standards/list-of-standards/ias-38-intangible-assets/).

## 손익·현금흐름 연결 및 중복 확인

```text
C = 연결 외부매출 × 산업 R&D 참고비중 × 분석상 개발투자 전환계수
e = C 중 기존 손익에 이미 비용반영된 비중
A = 해당 기간의 신규 개발자산 상각
조정 EBIT = 기존 EBIT + e×C − A
조정 D&A = 기존 D&A + A
FCFF = 조정 EBIT − 영업 현금세금 + 조정 D&A − 기타 CAPEX − C − ΔNWC
```

이번 채택 `e=0`: 기존 비용의 가산 없이 신규 상각 차감, 현금흐름에서 신규 지출 C 전액 차감. 세전 현금흐름 증감 `−(1−e)×C`; `e=1`로 바꿀 경우 순수 재분류만으로 세전 FCFF가 증가하지 않는 검증 필요. 현금세금은 회계 재분류 자체와 분리. 이번의 장부·세무상각 일치, 즉시 공제·크레딧 제외는 법률 검증 결론이 아닌 모델 입력 가정.

- 내부거래 제거 후 외부매출에만 적용. 양 법인 총매출에 각각 곱한 후 단순 합산하는 중복 제외.
- 기존 자금배분 **10억 R&D**와 계획 **5억 R&D 설비 CAPEX**의 실제 프로젝트 대사 필요. 연구설비 유형자산과 개발비 무형자산의 구분. 추가 예산 가정은 원자료와의 중복 부재를 입증하지 않으므로 해당 지출 확정 시 재대사.
- g=0에도 C의 반복 지출 유지. 완전히 성숙한 정상상태에서 연간 투자가 일정하면 **A=C**. 5년 코호트가 아직 성숙하지 않은 실제 초기기간과 정상상태를 구분.
- 템스코만 비용을 자산화해 EBIT를 높이고 DNP의 비용처리 EBIT 배수를 그대로 적용하는 방식 제외. 이번 정상상태에서 A=C인 완전 비용부담 EBIT 사용은 비교 취지에 부합하나, DNP의 비영업자산 미조정 등 기존 제한은 유지.

범위 제한: 이번 한정 조사에서 BOK의 직접 자산화율 통계 또는 회계기준을 통일한 공시 peer의 당기 자산화율 집계 확보 완료로 주장하지 않음. 회사 개발비 기초잔액, 가용시점, 자산인식 요건, 세무 처리, 실제 R&D 총액은 추가 확인 대상.
