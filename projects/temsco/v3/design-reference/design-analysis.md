# S08 디자인 참조 분석 — TEMSCO V3 적용안

대상: `analysis/manifest.json`의 S08 「파인원 주식회사 IR_250907.pdf」. **PDF 실제 순서 1–36페이지** 기준이며 문서 하단의 인쇄 페이지 번호와 구분한다. 원본 36페이지 전체 렌더링·접촉표 검토, 주요 페이지 12·13·15·28 확대 검토 완료. 원본 SHA-256 일치, 원본 수정 없음.

범위: **레이아웃·정보 위계·도식·타이포그래피·배색·사진 배치 방식**. 사업 내용·수치·시장 추정·사진·도면·고객 로고·기업 로고의 TEMSCO 이식 제외. 아래 이미지들은 분석용 참조이며 TEMSCO 웹·PDF에 삽입할 소재가 아님.

## 1. 핵심 관찰

S08의 변주는 색이나 아이콘 개수보다 **서로 다른 질문에 서로 다른 정보 구조를 배정하는 방식**에서 발생한다. 실적에는 차트, 사업 구성에는 분기 다이어그램, 경쟁력에는 비교표, 제조에는 공정 흐름, 실행에는 시간축, 인프라에는 실물 사진, 투자이력에는 두 개의 병렬 표를 사용한다.

TEMSCO V3도 재무 중심의 목차와 Navy/Cobalt 체계를 유지하면서 **전폭 표 → 전폭 표 → 전폭 표의 연속을 줄이는 방식**이 적합하다. 계산 근거가 필요한 손익·FCFF 표를 억지로 도형으로 바꾸기보다, 앞뒤 페이지를 요약 차트·브리지·시간축·비대칭 도식으로 구성하는 방향이다.

## 4. TEMSCO V3에 권장하는 9가지 페이지 형식

| 형식 | 적용 주제 | 구성 원칙 |
|---|---|---|
| A. 대목차 간지 | 과거 실적/시장·매출/가치평가/투자·회수/근거 | 큰 섹션 번호 + 명사형 제목 + 하위 논점 + 절제된 가장자리 색면 |
| B. 실적 대시보드 | 과거 실적 분석 | 매출 추이와 손익 추이 2개 큰 차트 + 작은 사실 인셋 1개 |
| C. 원인 브리지 | 적자 원인/대손 조정/내부거래 제거 | 넓은 워터폴 + 오른쪽 핵심 해석 + 하단 대사표 |
| D. 비대칭 구조도 | 인수 판단/자회사 시너지/시장 범위 | 2/3 폭의 관계도 + 1/3 폭의 가정·증거 요약 |
| E. 핵심 열 강조 비교 | 경쟁사/WACC/정상화 가정 | 표 전체 장식 최소화 + 핵심 열 또는 조건부 입력 한 곳 강조 |
| F. 단계별 계산 흐름 | 시장 기반 매출/FCFF/EV→주주가치 | 4–6단계 연결 + 단계별 입력 상태 + 하단 상세 계산표 |
| G. 공통 시간축 | CAPEX/운전자본/후속 투자유치 | 월·분기 축 + 3–4개 실행 트랙 + 자금 부족·납입 시점 표시 |
| H. 민감도 행렬 | TV/마진/운전자본 민감도 | 큰 중심 행렬 + 기준 가정 강조 + 우측 영향 방향 설명 |
| I. 좌우 연계 표 | 손익 및 현금/지분 및 회수 | 왼쪽 기준값·현재 상태 + 오른쪽 변화·산식/라운드 결과 |

고밀도 원표는 그대로 남길 수 있다. 다만 원표 앞뒤에 같은 모양의 표 페이지를 연속 배치하지 않고 관련 차트·브리지·흐름을 배정한다. 페이지마다 3개 박스나 아이콘을 추가하는 방식은 변주 효과가 제한적이다.

## 5. 차트·사진 적용의 구체적 경계

- 차트: TEMSCO 원자료·현재 계산식만 사용, 출처·기간·단위·연결 범위 유지
- 과거/미래: 실선/점선 또는 명시적 구간 분리, 동일 축 기준
- 음수 손익: 0 기준선과 음수 방향 유지, 상승 서사에 맞춘 축 왜곡 제외
- 도넛: 서로 중복되지 않는 같은 기준일·연결 범위의 구성비에만 사용
- 워터폴: 시작값 + 증감 = 종료값 대사, 내부거래·대손 효과 중복 반영 제외
- 시간축: 확정/예정/조건부 일정 구분, Series B/C 시기·금액의 임의 확정 제외
- 사진: TEMSCO/WEforms의 확인된 시설·제품·인물 자료가 있을 때만 사용
- 사진 부재: 단색 운영 흐름도·대형 숫자·원자료 기반 차트로 대체, 타사 설비사진이나 사실처럼 보이는 가상 시설 이미지 삽입 제외
