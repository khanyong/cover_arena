## 4. 산업 운전자본율

- 출처: [NYU Global Working Capital](https://pages.stern.nyu.edu/~adamodar/pc/datasets/wcdataGlobal.xls), 2026-01-05 자료
- 정의: NCWC=(유동자산−현금)−(유동부채−단기이자부채)
- 산업비율: 업종 합산NCWC/합산매출 / 단순 기업별 평균과 구분
- 글로벌 전자업종의 대용: 국내 마스크 전용 평균·템스코의 실측 비율과 구분
- 특수화학 비교비율18.8852%: 대체 검토자료 / 두 업종 임의 평균 제외
- 연말 NCWC = 연결 외부매출×18.42233324%×시나리오 배율
- 낙관14.73786659% / 중도18.42233324% / 비관22.10679989%
- 2025말 기초 대용 = 2025 연결매출342.61655569×산업비율 =63.11796362억
- 공통 평가일 대용 = 위 기초 +(중도2026말 NCWC−위 기초)×251/365
- 평가일 대용잔액: 72.24068884억 / 3개 시나리오 및 단일변수 비교에 공통 고정

- 기존 핵심3계정 NWC22.63781766억: 역사 참고 / 전체 NCWC 산업율과 가산·혼용 제외

## 5. 개발투자 및 무성장 안정기

- 출처: [NYU Global Margin Data](https://pages.stern.nyu.edu/~adamodar/pc/datasets/marginGlobal.xls), 2026-01-05 자료
- 산업 R&D/매출4.25030810%×분석 가정20%=추가 자산화 지출/매출0.85006162%
- 20%: 관측된 산업 자산화율의 명칭·표현 사용 제외
- 회사 총R&D를 매출의4.25%로 대체하는 모형과 구분
- 나머지 산업 R&D80%의 별도 추가 비용화 제외 / 기존 회사 R&D비용은 원가·판관비 내 유지
- e=0: 신규 개발투자는 기존 회사 비용 밖 추가 예산 / 회사 기존 비용의 환입 제외
- 각 법인의 연결 외부매출 비중으로 개발투자 배분 / 내부매출 기준 이중 배분 제외
- 손익: 개발비 상각 반영 / FCFF: 상각 가산 후 자산화 지출 차감
- 2026 연간 개발투자3.52459008억 / 잔여 지출1.10083088억
- 자산 코호트: 연간 취득 기준 / 현금흐름: 평가일 이후 지급 기준 / 실제 지급시점·미지급금 대사 예정
- 기존70억 사용안 중 R&D10억·회사 CAPEX 계획과 신규 개발예산의 중복 검토 필요
- 안정기 개발상각=계속 지출되는 연간 개발투자 / 성숙 자산구조의 단순화 가정
- 정상 EBIT = min(말년EBIT+말년개발상각−성숙개발상각, 회사2028마진×말년매출)
- 동일 정상 EBIT의 DCF·EV/EBIT 양쪽 적용 / 초기 자산화에 따른 일시 이익 증대의 배수 적용 방지
- 안정기 비개발 D&A=유지CAPEX / 총상각=비개발상각+개발상각 / 개발비 별도 차감
- 명목 영구성장률g=0 / 유지설비·개발투자의 실질 지속 가능성 별도 확인
