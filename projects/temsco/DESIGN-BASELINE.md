# 템스코 제3안 디자인 기준

> 이 문서는 최초 복제 시점의 보존 기록이다. 이후 사용자의 전문 투자자 대상 재구성·디자인 업그레이드 지시로 제3안에 새 디자인을 적용했다. 현재 제3안 기준은 [v3/AUTHORING.md](v3/AUTHORING.md)를 따른다. 초기원본과 기존 최종본은 그대로 유지한다.

기준일: 2026-09-08. 최신본 `pages/temsco/deck.tsx`를 복제하여 `pages/temsco/deck-v3.tsx`를 새 작업본으로 준비했다. 이 문서는 코드에서 확인한 디자인 기준이며, 새 원고를 반영할 때 동일성을 유지하는 기준이다.

## 버전과 작업 범위

| 버전 | 독립 파일 | URL |
| --- | --- | --- |
| 초기원본 | `pages/temsco/original.tsx` | `/temsco/original` |
| 최종본 | `pages/temsco/deck.tsx` | `/temsco/deck` |
| 제3안 · 작성 중 | `pages/temsco/deck-v3.tsx` | `/temsco/deck-v3` |

공통 허브 `/temsco` 상단에 버전 선택 카드가 있다. 제3안은 최종본을 import하거나 재수출하지 않는 별도 복제본이다. 이후 원고·수치·슬라이드 변경은 제3안 파일에만 적용한다. 공통 Tailwind·전역 CSS·폰트 설정을 바꾸면 기존 버전에도 영향을 주므로 이번에 변경하지 않았다.

제3안에는 최신본의 기존 본문을 준비용으로 복제했다. 새로운 제안 내용이 확정된 상태는 아니다. 제3안 표시와 최종본 링크는 인쇄에서 숨겨지는 상단 조작 영역에 있다. 새 PDF를 전달할 때에는 새 원고의 표지 날짜·버전 표기도 확정해야 한다.

## 규격과 인쇄

- 화면 슬라이드: 1123 × 794px, A4 가로에 가까운 비율. 16:9로 변경하지 않는다.
- `.temsco-slide`: 흰색 바탕, 테두리 1px `#cbd5e1`, 모서리 8px, 화면 그림자 `0 20px 35px -10px rgba(0,0,0,0.4)`.
- 페이지 번호: 우측 48px, 하단 24px, 15px/700, `#94a3b8`.
- 인쇄: A4 landscape, 여백 0, 슬라이드 폭 100%/최대 297mm, 높이 209mm, 마지막 장을 제외한 장마다 페이지 나눔.
- 인쇄 시 그림자·필터·모서리·조작 UI 제거, 배율 해제, 색상 보존. 기존 인쇄 CSS를 유지한다.
- 화면 배율: 1123/794 기준, 0.4~1.4 범위. 발표·스크롤·전체화면과 키보드 조작 유지.

## 글꼴과 글자 계층

Noto Sans KR의 300/400/500/700/900을 Google Fonts로 불러오지만, 최상위 컨테이너에는 `font-sans`가 지정되어 있다. Tailwind 설정에 `fontFamily.sans` 재정의가 없으므로 본문은 Tailwind 기본 sans 스택(`ui-sans-serif`, `system-ui`, `sans-serif`, 시스템·이모지 폰트)을 따른다. **폰트 로드만으로 Noto Sans KR이 실제 본문에 적용된다고 판단하지 않는다.** 제3안은 이 상태를 그대로 보존한다. 실제 사용 글리프는 OS와 브라우저에 따라 다르다.

| 용도 | 기존 기준 |
| --- | --- |
| 장 제목 | 주로 2rem(기본 16px 기준 32px), 900, slate-800 |
| 제목 예외 | 기업 개요 2.2rem, 투자유치 장 1.95rem |
| 카드 소제목 | 주로 20~24px, 700 또는 900 |
| 설명 본문 | 주로 13~16px, 400~500, slate-600/700 |
| 재무표 | 주로 10.5~12.5px, 주요 결과 700~900 |
| 큰 투자금 수치 | 38px, 900, blue-900 |
| 주요 강조 | `font-bold` 700 / `font-black` 900 |

원본의 `leading-tight`, `leading-relaxed`, `leading-snug`, `break-keep`를 문맥별로 유지한다. 새 문구가 넘치면 문장 길이·줄바꿈·내용 분량부터 조정하고 전체 글씨를 일괄 축소하지 않는다.

## 레이아웃과 구성

- 제목 아래 blue-600의 4px 밑줄과 장별 여백 유지.
- 주요 내부 패딩: `p-10`(40px), 일부 장은 더 넓은 패딩. 최종 투자안은 `p-10 pt-8 pb-7`.
- 좌우 2열, 4개 카드, 단계별 공정, 연혁, 고객별 카드, 재무표를 장 내용에 따라 사용한다.
- 카드: 흰색/밝은 slate·blue 바탕, 얇은 테두리, `rounded-xl/2xl`, 화면에서 작은 그림자.
- 재무표: 좌측 항목, 연도별 열, 매출·이익 행 강조, 손실 적색, 추정 연도 청색, 마지막 목표열 황색/짙은 청색.
- 도표는 기존 HTML/CSS와 SVG 유지. 도넛은 r=58, strokeWidth=26이며 중앙 합계와 범례를 함께 변경한다.
- 표지의 반도체 배경 이미지(Unsplash URL)와 Font Awesome 6.4.0 아이콘을 계승했다. 외부 리소스 의존성은 동일하다.

현재 11장 순서: 표지 → 투자 하이라이트 → 기업 개요 → 사업 시너지 → 리스크 설명 → 고객 파이프라인 → 수익성 전환 → 부문별 매출 → 추정손익 → 투자 후 재무구조 → 투자금 활용.

## 작성 시 규칙

1. 제3안의 기존 장을 기반으로 문구·표 수치를 교체한다. 현재 최종본과 초기원본은 수정하지 않는다.
2. 장 추가·삭제 시 `TOTAL_SLIDES`, `slideTitles`, `getSlideClass`의 0부터 시작하는 인덱스를 일치시킨다.
3. 숫자를 변경하면 요약·표·도표·본문·범례의 동일 지표를 함께 점검한다. 기존 숫자 불일치는 `reports/temsco-ir-status-2026-09-08.md` 참고. 이번 준비에서는 재무·사업 내용을 수정하지 않았다.
4. 화면 및 인쇄 스타일을 변경할 때 기존 버전과 공유된 설정을 수정하지 않고 제3안 안에서 처리한다.
5. 최종 검수는 11장 전체 화면, 키보드 이동, 전체화면, 스크롤, PDF의 한 장당 한 페이지와 잘림 여부를 확인한다.

- 동일 구간 SHA-256: `2be4d6abebab568cf38c48d6ee4493fcb9a4345e61042693a610612d3b819b2d`.
- 제3안에만 컴포넌트명·브라우저 제목·상단 버전 표시/최종본 링크·실제 장 제목에 맞춘 선택 목차를 변경했다.
- 수정한 TSX의 TypeScript 구문 변환 진단 없음, `git diff --check` 통과.
- 허브·초기원본·최종본·제3안 모두 localhost HTTP 200. 허브의 세 경로 링크 확인. 최종본과 제3안 서버 렌더링 HTML의 main 및 style 블록 동일, 슬라이드 11개 확인. 기존 두 발표 파일은 Git diff 없음.
- 시각 검증용 브라우저 연결 및 agent-browser 실행 도구를 사용할 수 없어 실제 화면·PDF의 시각 비교는 수행하지 못했다. 본문 코드와 서버 응답 비교로 동일성을 확인했으며 시각 검수 완료로 간주하지 않는다.
